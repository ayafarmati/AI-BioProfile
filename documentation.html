AI Bio Profile Generator

Documentation technique détaillée et explication du code source

1. Vue d'Ensemble de l'Architecture

Le projet AI Bio Profile Generator est une application web qui permet de transformer un CV brut (PDF ou texte) en une présentation PowerPoint (PPTX) standardisée, visuellement professionnelle, et prête à être partagée.

1

Extraction Physique

Lecture du document PDF, extraction du texte brut via PyMuPDF (ou OCR de secours via Tesseract), et extraction intelligente de la photo de profil via l'analyse des métadonnées ou la détection faciale (OpenCV).

2

Analyse Sémantique (LLM)

Envoi du texte brut à un modèle d'IA local (Ollama - Gemma 2) pour transformer le texte déstructuré en un objet JSON normé contenant les compétences, projets, etc.

3

Génération PowerPoint

Injection des données validées et de la photo du candidat dans un template PowerPoint vierge en respectant des coordonnées spatiales précises via python-pptx.

2. Le Serveur Principal (app.py)

Le fichier app.py est le point d'entrée de l'application. Il utilise FastAPI, un framework Python moderne et très rapide pour créer des APIs.

Points Clés :

  • Hébergement des fichiers statiques : La fonction app.mount("/static", StaticFiles(...)) permet au serveur web de distribuer l'interface utilisateur (HTML, CSS, JS).
  • Endpoint /api/extract-file : Reçoit le fichier PDF uploadé par l'utilisateur. Il extrait le texte et la photo, puis appelle l'IA locale pour structurer le texte en JSON.
  • Endpoint /api/generate-ppt : Reçoit le dictionnaire JSON (potentiellement corrigé par l'utilisateur via le frontend). Il sauvegarde ce JSON puis lance le script generate_pptx.py avant de renvoyer le fichier binaire `.pptx` au client via FileResponse.

3. Le Moteur d'Extraction et d'IA (test_extraction.py)

C'est le cœur de "l'Intelligence" du système.

Extraction de Texte (extract_text_from_pdf)

Il utilise fitz (PyMuPDF) pour lire les paragraphes du PDF. Si la longueur du texte extrait est anormalement courte (< 150 caractères), il déduit qu'il s'agit d'un PDF scanné et active pytesseract (OCR) pour "lire" le texte à partir des pixels de l'image.

Extraction de l'Image (extract_image_from_pdf)

Une fonction extrêmement robuste qui :

  1. Scanne tous les objets images du PDF.
  2. Écarte les éléments qui sont des icônes (trop petits), ou des arrière-plans (trop grands).
  3. Calcule un score basé sur le format carré (aspect ratio) et la position de l'image (privilégiant le haut de la première page).
  4. Fallback OpenCV : Si aucune image n'est trouvée (PDF totalement aplati), il convertit le haut de la page en image, applique un CascadeClassifier d'OpenCV pour détecter un visage humain, et découpe l'image précisément autour du visage.

Connexion LLM (extract_cv_data)

Il crée une requête HTTP brute vers le port 11434 (le serveur Ollama local). Un prompt "Système" puissant instruit le modèle de se comporter comme un recruteur expert et force la sortie de l'IA au format JSON. Cela garantit que les données envoyées au frontend sont toujours des paires clé/valeur exploitables.

4. Le Moteur de Génération Visuelle (generate_pptx.py)

Le module responsable de la phase 3. Il utilise python-pptx pour manipuler un fichier PowerPoint (.pptx) comme s'il s'agissait de code XML.

Logique de fonctionnement :

  • Il lit le fichier resultat_cv.json enregistré.
  • Il ouvre le fichier template BioPofile_Template.pptx.
  • Le positionnement Absolu : Le script utilise des coordonnées spatiales exprimées en Emu (English Metric Units). Une valeur en Emu permet un placement au pixel et millimètre près sur la diapositive PowerPoint.
  • La fonction add_text_box : Une fonction utilitaire qui crée une boîte de texte, insère un paragraphe, gère l'alignement, applique la taille de police (en points Pt), et gère le gras.
  • Formatage intelligent : Les compétences (Hard Skills, Soft Skills) ne sont pas injectées n'importe comment. Elles sont concaténées par des virgules pour s'adapter élégamment aux encarts visuels réduits. Les projets sont positionnés à intervalles fixes (offset_y) pour s'empiler proprement.
  • L'Injection d'Image : La méthode slide.shapes.add_picture() insère la photo (récupérée de /static/temp_photo.png) exactement aux coordonnées de l'emplacement prévu sur le bandeau gauche de la présentation.

5. L'Interface Frontend (static/)

Le Frontend ne nécessite pas de Framework lourd (React/Vue). C'est du HTML/CSS/JavaScript Vanilla pur, ce qui le rend ultra-léger et rapide.

L'architecture du Frontend :

  • index.html : Définit la structure : la sidebar avec la Dropzone (zone de glisser-déposer), et le panneau principal qui change d'état (État vide -> Loader Squelette -> Formulaire de Validation généré dynamiquement).
  • style.css : Utilise des variables CSS pour un thème moderne et "Verre" (Glassmorphism). Les animations comme les Skeleton Loaders assurent une excellente expérience utilisateur pendant que l'IA réfléchit.
  • script.js :
    • Gère les événements Drag & Drop de fichiers.
    • Utilise fetch pour envoyer le PDF à l'API.
    • La fonction buildForm(data) : Est extrêmement dynamique. Elle lit le JSON de l'IA et crée des inputs HTML à la volée. Elle détecte si la donnée est un texte simple, un tableau (liste de compétences), ou un objet imbriqué (un projet avec titre et description), et crée le bon élément visuel (input, textarea).
    • La fonction gatherFormData() : Fait l'inverse. Elle lit le formulaire HTML modifié par l'utilisateur et le re-transforme en JSON propre pour l'envoyer à la génération.
    • Le Téléchargement : Lors du retour du fichier PPTX par l'API, le script crée un objet binaire (Blob) en mémoire, crée un lien de téléchargement caché, simule un clic dessus, et permet le téléchargement du fichier généré pour l'utilisateur sans recharger la page.
